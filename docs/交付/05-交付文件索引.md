# 交付文件索引

当前版本是可演示的前端系统（仓库版本 1.0.0）。业务统计、工单、告警和监控画面为演示数据；数字应急工况读数与设备状态为脚本推演值，非实时测点、无设备指令回传；隧道施工 BIM 与局部竣工 BIM、双层路面采样与风机位置为真实三维数据。165 个可独立定位的竣工构件来自模型目录，整段合并灯具不拆成虚假设备。

## 各文件现在补了什么

- 使用说明：演示脚本、五条告警、默认图层、分模块讲解点、现场问答。
- 思维导图：演示串联、模块与图层对照、点位来源、数据口径。
- 原型说明：每页区块、资产四页签、场景操作反馈、故意不做的交互。
- 功能清单：可勾选的 12 步、能力是否联动场景、哪些按钮不算通过项、孪生工况推演的进入/退出恢复与数据边界。
- 思维导图 PNG、说明文档 DOCX 已于 2026-11-11 同步为“四维工况推演 / Cesium 主视图 / 非实时测点”口径，并校正模块默认分组表。

源码里的 `src/prd.ts` 是早期功能设想（实时视频、工单引擎、权限等），运行界面已不再提供 PRD 编辑。以本目录和 README 描述的可运行行为为准。
