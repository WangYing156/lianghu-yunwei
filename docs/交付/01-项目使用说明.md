# 两湖隧道（南湖段）智能运维管理平台 · 使用说明

给项目负责人、演示讲解人和现场验收人员。研发环境、模型部署和回归命令的完整说明见仓库根目录 [README.md](../../README.md)。

## 1. 这是什么

这是一套可运行的隧道运维三维可视化前端，对象是两湖隧道南湖段。页面用 Cesium 同时展示施工 BIM 与局部竣工 BIM，在总览、智能交通、智慧养护、智慧监测、数字应急、数字服务、资产资料中心七个模块里查看设备点位、告警和构件资料。

当前交付形态是**可演示的前端系统**：

- 施工模型、局部竣工模型和其中可独立定位的设备几何，来自真实 BIM。
- 告警、工单、流量、物资、健康指数、视频画面是演示数据，写在前端，刷新页面会回到初始内容。
- 孪生工况的遥测读数、设备状态和处置阶段也是**脚本推演值**，与真实 BIM 几何、双层路面、风机模型位置分开标注；不下发设备指令，不冒充实时测点。
- 没有登录、权限、物联网接口和真实视频流。讲解时按“看界面、走场景、讲业务闭环”，不要说成已上线的生产系统。

## 3. 怎么打开

需要 Node.js 22 和可使用 WebGL 2 的桌面浏览器（建议 Chrome）。笔记本集显可以打开，剖切和巡游时把浏览器窗口放到前台，避免后台标签页把画面降帧。

```bash
npm ci
npm run dev
```

浏览器打开 `http://localhost:5188`。路由是哈希地址，默认进入 `#/overview`（总览）。开发服务监听 `0.0.0.0`，同一局域网的其他电脑可以用本机 IP 加端口 5188 访问。

未配置天地图密钥时，不要打开在线底图，BIM 仍可独立查看。需要影像底图时，将 `.env.example` 复制为 `.env.local`，填写 `VITE_TIANDITU_TK`，然后重新执行 `npm run dev`。

随仓库提供的模型：

- `public/三维数据/全局隧道施工模型/`：施工 BIM，默认半透明，用来交代整段空间关系。
- `public/三维数据/局部隧道竣工模型/`：带设备的竣工段，内部巡游和 165 个独立构件都在这一段。
- `public/三维数据/两湖倾斜/`：倾斜摄影，Git 不收录。目录不在时场景会提示并跳过，不影响竣工 BIM。

## 4. 建议演示路径（约 15 分钟）

按这个顺序讲，每一步都有可见反馈。不要从“审核”“新建任务”这类按钮起讲，它们多数只是界面，不会写入后台。

1. **总览（2 分钟）**  
   指出左侧告警、交通状况、重点监控，右侧设备在线率和工单。点一条告警或右上角铃铛，镜头飞到对应点位。点一张重点监控缩略图，弹出标注“模拟画面”的窗口，并定位摄像机。
2. **场景能力（5 分钟）**  
   仍留在总览或切到资产页。依次演示：图层开关、点位聚合开/关、剖切（先切竣工段）、点选一个竣工设备看暖橙高亮、进入内部巡游再按 `Esc` 退出。
3. **一个专业页（4 分钟）**
   建议数字应急：上方是应急场景，中间是火灾排烟、防洪排涝、交通事故流程和物资，下方是四维工况推演。切换四种工况，点“进入孪生仿真”，**上方 Cesium 主视图直接变成当前工况的推演场景**；点步骤暂停检视，切换三维/第一人称/立体分屏，再用 HUD 的“退出推演”恢复原场景。强调读数与设备状态是脚本推演值。交通事故流程文字应为浅色，能在深色底上读清。
4. **资产资料中心（3 分钟）**  
   左侧搜一台风机，点列表，右侧打开资料面板并定位。再点场景里的设备钉或 BIM 构件，确认还是这一块面板，不会再冒出第二张场景小窗。未建档构件显示模型属性，版式不变。
5. **收口（1 分钟）**  
   用第 8 节的口径说明：几何是真的，业务数和视频是演示的。

若时间只够 5 分钟：总览告警定位 → 剖切竣工段 → 资产页同一资料面板 → 说明数据边界。

| 智慧养护 | `#/maintenance` | 病害点位、发现到归档的闭环数量、健康指数、病害图表、巡检与周期维护 |

| 数字应急 | `#/emergency` | 应急场景、火灾排烟、防洪排涝、事故流程、物资、主视图孪生工况推演 |

告警横幅只出现在总览、智慧监测、数字应急。五条演示事件固定不变，轮播不会自己新增告警：

| 时间 | 等级 | 来源 | 内容 | 桩号 |
| --- | --- | --- | --- | --- |
| 14:12 | 紧急 | 数字应急 | 积水液位快速上升 | K3+050 |
| 13:48 | 重要 | 智能交通 | 违停事件待确认 | K3+050 |
| 13:20 | 重要 | 智慧养护 | 交通诱导屏离线 | K3+400 |

点击横幅、告警卡片或铃铛会定位到该事件自己的点位。若对应图层被关掉，系统会先打开图层再飞过去，不会点了没反应。详情里会标明这是模拟事件。

鼠标悬停或键盘聚焦横幅时暂停轮播；浏览器切到后台也会暂停。系统开启“减少动效”时，自动轮播、呼吸动画和巡游自动播放停止，仍可手动点选。

## 6. 三维场景怎么用

七个业务页共用同一套场景。总览和资产页是全屏；其余模块上方是一块可拖高的场景，下方是本专业的表和统计。场景底部工具栏从左到右：

- **图层**：隧道环境、环控系统、交通管控、结构监测、隧道机电。每组可再勾子类，例如摄像机、风机、病害、积水监测。
- **点位聚合**：在图层面板里开关。开启时，远景把重叠的普通设备收成数字，点击数字后拉近，并列出全部成员，不会丢掉被收起来的设备。关闭后始终显示单个设备钉。告警和当前选中点不进普通聚合，避免被数字盖住。
- **场景设置**：底图、二维/三维、施工/竣工显隐、透明度、环境光。默认折叠。路面保持模型原始材质；只有单独打开“路面透视”时道路才变透明。
- **剖切**：目标可选全部 BIM、竣工段或施工模型，沿 X、Y、水平 Z 拖动，可反向保留。“重置剖切”恢复完整模型。切开后能看到青色网格切割面和亮边。施工模型和竣工模型原点不同，剖切按同一世界平面分别换算，不会错开一刀。
- **内部巡游**：沿竣工模型真实路面进入内部。从当前路线末端朝里走，可暂停、换下层/上层、调速度、按名称或构件编号检索设备。拖拽或滚轮会暂停播放，方便环视。`Esc` 或退出按钮回到外部视角，并恢复刚才的剖切和侧栏。
- **孪生工况推演**：从数字应急面板“进入孪生仿真”后，普通工具栏暂时让位于推演 HUD；图层/剖切/复位/内部巡游/二维切换不会与推演相机争抢控制权。退出后恢复进入前的相机、图层、气流、透视与巡游设置。
- **放大场景**：场景铺到页面顶层，`Esc` 退出。业务页里场景偏矮时，进入巡游或推演会自动加高，退出后回到原来的高度。
- **复位**：回到默认视角。

无文案的场景高度把手可用鼠标、触屏拖动，也可方向键、Home、End 调整，双击可快速变化。

各模块打开时的默认图层（可手动改，换页后按该页默认值重设）：

| 模块 | 默认打开 |
| --- | --- |
| 总览 | 全部图层 |
| 智能交通 | 交通管控 |
| 智慧养护 | 结构监测 |
| 智慧监测 | 环控系统、结构监测 |
| 数字应急 | 隧道环境、环控系统、隧道机电 |
| 数字服务 | 结构监测 |
| 资产资料中心 | 全部图层 |

默认分组已按各页面原始点位校正，避免开启没有点位的空图层；数字服务的投诉点位属于“结构监测”组。设备钉按类别分色：交通蓝、机电青、环控绿、监测橙、结构紫。告警为红色水滴并带光晕，预警为橙色。选中构件为暖橙色高亮，并叠加呼吸光斑。镜头进入约 45 米内时隐藏 BIM 图标，以免挡住模型；退到约 65 米外再显示。巡游过程中外部图标隐藏，只看模型本身。

二维模式会暂停剖切并隐藏 BIM 图标，保留路线。在二维里反复定位同一设施，范围保持稳定，不会越点越远。回到三维后，恢复进入二维之前的剖切状态。

点位有两类，讲解时不要混：

- **业务点**：按桩号放在场景里的示意点，例如病害、投诉、各页自带的监测点，以及五条模拟告警。
- **竣工构件**：从竣工模型目录读出的 165 个可独立定位设备（风机、摄像头、消防泵、探测器、广播、疏散指引等），坐标来自构件本身。整段合并导出的灯具不能拆成一盏一盏，系统不会为它们编造独立点位。

## 7. 各模块讲解时点哪里

### 总览

左右卡片盖在全屏场景上。点告警或监控缩略图会飞到对应点位，卡片仍留在两侧。打开构件详情、聚合成员列表、内部巡游或「放大场景」时，两侧卡片会暂时让开，关闭或按 `Esc` 后恢复。监控窗可拖动、放大，媒体加载失败时可以重试，并提供“重新定位”。

右侧设备在线率、工单四态（待派发 6、处理中 14、待验收 3、已完成 128）和公众服务数字都是固定演示值。

### 智能交通

上方场景默认只开环境和交通管控。下方视频墙可在 4、9、16 分格之间切换，画面是示例图，带“REC”和个别“AI事件”角标，不是实时轮巡。交通事件表的“定位”“确认”是展示按钮，不会改状态、也不会飞到场景。

诱导屏区域可以改文字、等级、时段和渠道。内容为空时会提示先填写；提交后本页表格多一条“待审核”记录，并提示待值班长审核。刷新后这条记录消失，没有发到真实情报板。

### 智慧养护

上方是病害点位。中间左侧是“发现 → 派发 → 维修 → 验收 → 归档”数量和工单表，来源分成人工巡检、AI 识别、公众反馈。右侧是分区健康指数，其中一段标成重点观察。下方是病害类型、趋势，以及巡检完成率和周期维护计划。“新建巡检任务”没有后续页面。

### 智慧监测

上方是环控与结构点位，部分点位带历史曲线数据。下方四块：环境气体、环境照明、新风换气设备表、沉降/变形测点。告警横幅在本页可见，可定位到模拟照度或积水事件。数值不会随时间跳动。

### 数字应急

上方场景可拖高。火灾排烟给出烟感、消火栓、灭火器和联动策略标签（排烟、疏散指引、广播、卷帘）。防洪排涝有一条固定红色预警文案和液位曲线。交通事故是四步流程说明加统计，流程文字为浅色。物资是库存数字和物资点“充足 / 需补充”。

“四维工况推演”是数字应急面板，推演画面是**同一个 Cesium 主视图**，不是另开的示意视窗、页面联动按钮或头显系统。选择四种工况（火灾疏散、积水排涝、交通事故、日常巡检）后，点“进入孪生仿真”或“全屏沉浸”；主视图按脚本步骤同步切换相机、真实竣工模型上的特效、16 台风机转速与气流方向、情报板、疏散/绕行标志、告警点和设备状态；消防车/疏散车、泵站叶轮/绕行车、事故救援/清障/过车分道演进，车辆逐帧避开标线、诱导线、积水、泵站、锥桶及相邻车辆。

页面卡片和场景 HUD 都标明“工况推演值 / 非实时测点”，HUD 另显示车辆净距校核结果。页面可看每步时长与暂停状态，HUD 可切步骤（会暂停）、播放/暂停、调速、切三维/第一人称/立体分屏、放大场景和退出；切工况默认从头推演，已退出时保留上次步骤供预览。立体分屏是 Cesium 的 Cardboard 双视图，仅在三维透视模式可用，**不是 WebXR 头显**。全屏沉浸时中间业务卡片先隐藏，退出推演后恢复原场景和用户设置。

### 数字服务

上方是投诉点位。下方是反馈表（含待审核、已转工单、已关闭）和预警发布记录（级别、渠道、触达量）。安全教育是四条标题和浏览量。“审核”“新建发布”“进入安全教育专区”没有独立页面。

### 资产资料中心

左侧按“图层分组 → 子类 → 设备”折叠，可按名称、编号、桩号搜索。右侧面板四个页签：三维模型、结构·参数·材质、作业指导、技术资料。列表点击、设备钉点击、BIM 构件点击（含右键）都打开这一块，并在能按名称对应时高亮左侧同一项。

“更新设备”“维护工单”只在当前页面给出成功提示，不进入养护模块的工单表，刷新后恢复。未建档构件不套用风机、摄像头那套台账，改为展示该构件的模型属性。

## 8. 演示时怎么讲数据

可以讲：

- 施工 BIM 与局部竣工 BIM 是真实模型；竣工段内 165 个独立构件可以定位、高亮、剖切和巡游检视。
- 七个模块把交通、养护、监测、应急、服务和资产放在同一套场景里，换页只换默认图层和业务卡片。
- 告警能定位，监控窗能对上摄像机锚点，资产列表和场景拾取共用一套资料面板。

不要讲成已经具备：

- 实时视频、云台、GB28181 或视频墙真轮巡。
- 实时物联网、告警推送、工单流转、物资出入库、公众小程序。
- 账号、值班长审核、操作留痕。
- 头显 VR / WebXR、AI 识别服务、诱导屏真实下发。
- 实时测点驱动的工况推演、真实风机/水泵/情报板指令回传。
- 倾斜摄影（除非现场已经另行放入 `public/三维数据/两湖倾斜/`）。

业务按钮若只弹出提示或没有反应，直接说明“这里展示闭环样子，数据停在浏览器里”。

## 9. 现场常见问题

| 现象 | 处理 |
| --- | --- |
| 画面黑或只有底色 | 换桌面 Chrome，确认 WebGL 2 可用；不要用过旧的集成显卡远程桌面硬解。 |
| 没有卫星影像 | 未配 `VITE_TIANDITU_TK` 或密钥无效。关底图，只看 BIM。 |
| 提示缺少倾斜摄影 | 预期行为。继续看竣工 BIM。 |
| 点了设备没有资料面板 | 先确认在资产资料中心。其他页点击以定位和高亮为主；资产页才打开右侧四页签。 |
| 远景只有数字、看不到单个钉 | 点位聚合开着。点数字拆开，或关掉聚合。 |
| 剖切后模型缺一块 | 拖回位置，或点“重置剖切”。二维和巡游会暂时停用剖切，返回三维或退出巡游后恢复。 |
| 巡游进不去 | 需在三维（不是二维）下对竣工模型使用。路线来自当前竣工路面，换模型后要重新校准，见 README。 |
| 推演中底部工具栏不见了 | 预期行为。推演 HUD 接管场景控制；点 HUD 的“退出推演”后恢复常规工具栏和进入前的设置。 |
| 立体分屏按钮不可用 | Cesium Cardboard 分屏需在三维透视投影下使用；切回三维再试。它不是头显 VR 开关。 |
| 刷新后刚“发布”的情报板没了 | 预期行为。发布记录只存在当前页面内存。 |
