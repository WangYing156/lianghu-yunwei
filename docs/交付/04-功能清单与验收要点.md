# 功能清单与验收要点

验收对象是当前仓库可运行的前端。通过表示“页面上能稳定做完”，不表示已接入生产物联网、视频平台或工单系统。三维交互的 29 项浏览器记录见 [scene-interactions-qa.md](../scene-interactions-qa.md)，本文件是现场可勾选的业务验收单。

## 1. 建议现场路径

环境：桌面 Chrome，WebGL 2，窗口大约 1440×900 或更大。先 `npm run dev`，打开 `http://localhost:5188`。

| 步骤 | 操作 | 通过标准 |
| --- | --- | --- |
| 1 | 打开总览 | 能看到施工模型（上下文）和带设备的竣工段；左右卡片不被裁成无法阅读 |
| 2 | 点一条告警或右上角铃铛 | 镜头飞到对应点位；若图层原先关闭，会自动打开后再定位 |
| 3 | 点一张重点监控 | 弹出窗口，画面标有“模拟画面”，并可重新定位 |
| 4 | 打开「点位聚合」 | 远景普通设备变为数字；告警仍是独立红/橙点 |
| 5 | 点击聚合数字 | 飞近并列出成员，能选中其中一个看到模型 |
| 6 | 关闭聚合 | 设备钉始终分开 |
| 7 | 打开剖切，分别切竣工段和施工模型并拖动 | 有青色网格切割面和亮边；重置后模型完整 |
| 8 | 切到二维再切回三维 | 二维能看到路线；回来后剖切状态还在 |
| 9 | 点一个竣工设备 | 暖橙色高亮，周围有呼吸光斑 |
| 10 | 进入内部巡游，换一层，按 Esc | 从路面末端进入；退出后外部视角和侧栏恢复 |
| 11 | 打开资产资料中心，点左侧一台风机，再点场景中的对应设备或构件 | 右侧始终是同一套四页签面板，不另出场景小窗 |
| 12 | 打开数字应急 | 交通事故流程文字为浅色；孪生 VR 能切换四种工况；“联动三维巡游”会带动上方场景 |

任一步失败，先看 [使用说明](./01-项目使用说明.md) 第 9 节的常见现象，再决定是环境问题还是缺陷。

## 2. 功能矩阵

图例：**场景联动** = 会改变三维镜头、图层、高亮或巡游；**本页示意** = 能看、能点，状态不进其他模块，刷新即回初始值。

| 能力 | 出现位置 | 场景联动 | 数据性质 | 验收时看什么 |
| --- | --- | --- | --- | --- |
| 七模块导航 | 顶栏 | 换页重建场景 | — | 七个地址都能打开，标题与菜单一致 |
| 告警横幅 / 面板 / 铃铛 | 总览、监测、应急；铃铛全局 | 是 | 五条固定模拟事件 | 定位到独立点，详情写明模拟 |
| 重点监控窗 | 总览、摄像机点、摄像机构件 | 是 | 示例图片 / GIF | 角标不是 LIVE，失败可重试 |
| 施工 / 竣工 BIM | 全部场景 | 是 | 真实模型 | 竣工段可近看；施工模型默认可作半透明背景 |
| 五类图层及子类 | 场景底栏 | 是 | 点位目录 | 开关立即生效；换页恢复该页默认图层 |
| 点位聚合 | 图层面板 | 是 | 真实构件 + 业务点 | 点击数字不丢成员；告警不进普通聚合 |
| 三轴剖切 | 场景底栏 | 是 | 真实包围盒 | 三轴、反向、三个目标、重置；二维和巡游时暂停 |
| 二维 / 三维 | 场景设置 | 是 | 路线与点位 | 重复定位不飞全球；返回三维恢复剖切 |
| 内部巡游 | 三维底栏 | 是 | 竣工路面采样 | 末端入场、换层、检索、Esc 恢复 |
| 选中发光 | 点构件时 | 是 | 真实构件 | 暖橙高亮 + 呼吸光斑 |
| 资产列表与资料四页签 | 资产页 | 是 | 演示台账；未建档构件用模型属性 | 列表与场景共用面板 |
| 视频墙 4/9/16 | 智能交通 | 否 | 示例画面 | 分格切换成功即可 |
| AI 事件表 | 智能交通 | 否 | 演示表 | “定位 / 确认”不作为通过项 |
| 诱导屏编辑 | 智能交通 | 否 | 本页内存 | 空内容有提示；提交后本表多一行 |
| 病害闭环与健康指数 | 智慧养护 | 场景仅展示病害点 | 演示表和图 | 五步流程和重点观察文案可见 |
| 环控与结构图表 | 智慧监测 | 场景展示监测点 | 演示表和图 | 气体、照度、风机、沉降四块都在 |
| 消防 / 排涝 / 事故 / 物资 | 数字应急 | 场景展示应急点 | 演示表和图 | 红色积水文案、浅色事故流程、物资状态 |
| 孪生 VR 四工况 | 数字应急 | 联动按钮为是 | 页内推演 | 四工况、步骤、全屏、联动巡游 |
| 反馈 / 预警 / 安全教育 | 数字服务 | 场景展示投诉点 | 演示表 | 三块内容可见；审核与教育专区不作为通过项 |
| 减少动效 | 操作系统偏好 | 停止自动播放 | — | 仍可手动定位和手动巡游 |

## 3. 已具备

- 七个业务模块、统一深色大屏导航、哈希路由。
- 施工 BIM、局部竣工 BIM；倾斜摄影和天地图底图为可选，缺失时跳过或关闭。
- 分类水滴设备钉；告警、预警独立强调且不参与普通聚合。
- 聚合开关、点击数字展开全部成员、近景隐藏图标。
- 三轴剖切、目标模型选择、青色网格切割面；跨施工/竣工坐标系；离开三维或进入巡游时暂停并在返回时恢复。
- 选中构件发光；路面默认保留原始材质。
- 竣工模型内部巡游：真实路面、上下层、速度、设备检索、结构透视与独立路面透视。
- 资产列表与场景点击共用资料面板。
- 告警定位时自动补开目标图层；示例监控窗与摄像机锚点联动。
- 告警轮播可暂停，并尊重“减少动效”。

## 4. 演示边界（不要写成缺陷，也不要写成已上线）

| 项 | 现状 |
| --- | --- |
| 实时物联网、告警接口 | 未接。事件列表固定 |
| 视频平台、云台、视频墙轮巡 | 未接。只有示例媒体 |
| 工单流转、物资库存、公众上报 | 未接。数字和按钮停在页面内 |
| 诱导屏真实下发、值班长审核 | 未接。交通页提交只改当前表格 |
| 账号权限 | 无登录 |
| 头显 VR、实时测点驱动推演 | 无。VR 是页内示意并可联动巡游路径 |
| 倾斜摄影 | 需按 README 另行放置，缺失时自动跳过 |
| 不可拆分的整段灯具 | 不单设备定位，避免伪造点位 |
| 换一套竣工模型后的巡游路线 | 必须重新跑路线校准，不能沿用旧采样 |

以下按钮**不纳入本轮通过条件**：智能交通事件“定位 / 确认”，养护“新建巡检任务”，服务“审核 / 新建发布 / 进入安全教育专区”，资产资料“查看”文件。它们表示流程位置。资产“更新设备 / 维护工单”只验收“有成功提示”，不验收写入养护模块。

## 5. 回归命令

现场若要留研发证据，在能编译的机器上执行：

```bash
npm test
npm run typecheck
```

浏览器脚本见 README 的 `npm run test:scene`（另开终端先启动 `npm run dev`，本机需有 Chrome）。单元测试覆盖路径、设备目录、图层、聚合、材质、剖切和告警等逻辑；浏览器脚本覆盖 29 项真实点击。失败时脚本以非零码退出。
