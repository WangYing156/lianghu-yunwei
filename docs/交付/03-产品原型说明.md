# 产品原型说明

当前原型就是可运行的 Web 页面，地址 `http://localhost:5188`，没有另外一套静态稿。下面按信息架构对照演示。交互的通过标准见 [功能清单与验收要点](./04-功能清单与验收要点.md)。

## 1. 全局框架

深色大屏。标题「两湖隧道（南湖段）智能运维管理平台」居中。导航分两列夹住标题：左侧总览、智能交通、智慧养护、智慧监测；右侧数字应急、数字服务、资产资料中心。右上角为日期时间与告警铃铛，铃铛数字为演示告警条数。

```text
┌────────────────────────────────────────────────────────────┐
│ 总览 交通 养护 监测 │ 平台标题 │ 应急 服务 资产 │ 时间 铃铛 │
├────────────────────────────────────────────────────────────┤
│ 告警横幅（仅总览 / 监测 / 应急；可点击定位）              │
├────────────────────────────────────────────────────────────┤
│ 业务卡片 或 全屏三维场景                                  │
│ 场景底栏：图层 · 场景设置 · 剖切 · 内部巡游 · 放大 · 复位 │
└────────────────────────────────────────────────────────────┘
```

进入数字应急的工况推演后，普通底栏暂时让位于场景 HUD；退出推演后恢复底栏和进入前的场景状态，避免图层、剖切、二维、复位和内部巡游与推演相机争抢控制权。

换页使用顶部导航，地址形如 `#/traffic`。页面切换会释放上一套三维场景。系统设置里若打开“减少动效”，横幅不再自动轮播，巡游和工况推演不自动播放，但仍可手动检视。

全局有一个可拖动的监控窗，总览缩略图、摄像机点位、竣工摄像机构件都可以把它打开。窗体标明“模拟画面”，可放大、重试、重新定位。

## 2. 总览 `#/overview`

全屏场景，左右各一列悬浮卡片。检视构件或聚合列表时，侧栏会暂时收起，关闭或 `Esc` 后恢复。

| 位置 | 卡片 | 原型里能做什么 |
| --- | --- | --- |
| 左上 | 重点告警 | 列出固定事件，点击定位 |
| 左中 | 交通状况 | 断面流量数字 + 趋势图 |
| 左下 | 重点监控 | 缩略图，点击放大并定位摄像机 |
| 右上 | 设施设备状态 | 六类在线/故障数字 + 饼图 |
| 右中 | 运维养护工单 | 待派发、处理中、待验收、已完成 |
| 右下 | 公众服务 | 今日反馈、满意度、在发预警 |

## 3. 专业页的共同骨架

智能交通、智慧养护、智慧监测、数字应急、数字服务都是：上方一块可拖高的三维场景，下方本专业的表、统计和流程。场景默认只打开与本专业相关的图层，图层面板里可以再加开。

场景高度用无文案把手调节，支持鼠标、触屏、方向键、Home、End 和双击。

### 智能交通 `#/traffic`

```text
┌─────────────────────────────────────────┐
│ 视频点位三维场景                         │
├──────────────────────┬──────────────────┤
│ 视频墙 4 / 9 / 16    │ AI 事件表        │
│ 示例画面             │ 交通状态色带     │
├──────────────────────┴──────────────────┤
│ 诱导屏 / 情报板：选设备、写内容、提交    │
│ 发布记录表（提交后仅本页追加）           │
└─────────────────────────────────────────┘
```

视频墙单元格可看到锁定、REC、个别 AI 违停角标，不能切真实码流。事件表的“定位”“确认”没有场景动作。诱导屏在内容为空时提示填写；提交成功后表格多一行“待审核”。

### 智慧养护 `#/maintenance`

```text
┌─────────────────────────────────────────┐
│ 病害点位场景                             │
├──────────────────────┬──────────────────┤
│ 闭环五步 + 来源标签  │ 分区健康指数     │
│ 病害工单表           │ 重点观察提示     │
├──────────────────────┼──────────────────┤
│ 病害类型 / 趋势图    │ 巡检完成率       │
│                      │ 周期维护计划表   │
└──────────────────────┴──────────────────┘
```

闭环五步：病害发现、审核派发、维修处置、现场验收、闭环归档。健康指数里有一段低于关注线的提示文案。“新建巡检任务”无表单。

### 智慧监测 `#/monitoring`

```text
┌─────────────────────────────────────────┐
│ 环控 + 结构点位场景                      │
├──────────────────────┬──────────────────┤
│ 环境气体数值与曲线   │ 照度、回路、在线率│
├──────────────────────┼──────────────────┤
│ 风机 / 新风 / 排烟表 │ 沉降图 + 测点表  │
└──────────────────────┴──────────────────┘
```

气体和沉降旁各有一条提示（NO₂ 偏高、沉降速率关注）。测点状态分为“正常 / 关注”。这些数不随时钟变化。本页有告警横幅。

### 数字应急 `#/emergency`

```text
┌─────────────────────────────────────────┐
│ 应急三维场景（推演 / 沉浸时加高）        │
│ 进入推演后：同一个 Cesium 主视图         │
│ HUD：步骤 / 播放 / 速率 / 视角 / 退出    │
├──────────────────────┬──────────────────┤
│ 火灾排烟设施与策略   │ 积水红色预警     │
│                      │ 液位曲线与泵表   │
├──────────────────────┼──────────────────┤
│ 事故统计 + 四步流程  │ 物资数量与点位   │
│ （流程文字为浅色）   │ 充足 / 需补充    │
├──────────────────────┴──────────────────┤
│ 四维工况推演：四工况、每步时长、状态    │
│ 工况推演值 · 非实时测点 / 退出恢复设置  │
└─────────────────────────────────────────┘
```

四工况：火灾疏散、积水排涝、交通事故、日常巡检。选择工况后点“进入孪生仿真”或“全屏沉浸”，上方 Cesium 主视图按脚本步骤统一切换相机、真实竣工 BIM 特效、16 台风机转速与气流方向、情报板、疏散/绕行标志、告警点和设备状态；页面卡片与 HUD 均标明“工况推演值 / 非实时测点”。切步会暂停以便检视，可播放/暂停、调速、切三维/第一人称/Cesium 立体分屏、放大和退出；切工况默认从头推演，退出后保留上次步骤供页面预览并恢复外部场景与用户设置。立体分屏是 Cardboard 双视图，不是 WebXR 头显；没有实时视频或真实设备指令回传。

### 数字服务 `#/service`

```text
┌─────────────────────────────────────────┐
│ 投诉点位场景                             │
├──────────────────────┬──────────────────┤
│ 公众反馈统计与表格   │ 预警发布记录     │
├──────────────────────┴──────────────────┤
│ 安全教育四条标题                         │
└─────────────────────────────────────────┘
```

反馈状态包括待审核、已转工单、建议采纳、已关闭。发布记录有红 / 黄 / 蓝级别和渠道、触达量。“审核”“新建发布”“进入安全教育专区”没有下一级页面。

## 4. 资产资料中心 `#/asset`

```text
┌──────────────┬─────────────────────────────┐
│ 资产列表      │                             │
│ 搜索          │        三维场景              │
│ 分组 → 子类   │   点击设备钉 / BIM 构件       │
│ → 设备        │   或右键构件                  │
│              ├─────────────────────────────┤
│              │ 右侧同一资料面板              │
│              │ 模型 / 参数 / 指导 / 资料     │
└──────────────┴─────────────────────────────┘
```

列表与场景点击打开同一块右侧面板。能按名称对应时，左侧该项高亮。面板页签：

| 页签 | 内容 |
| --- | --- |
| 三维模型 | 编码、桩号与位置、所属系统、安装日期；预览区为资料示意，精细几何仍在中间场景 |
| 结构·参数·材质 | 三组键值 |
| 作业指导 | 分步标题和说明 |
| 技术资料 | 文件名、大小、日期、版本；“查看”为展示按钮 |

底部“更新设备”“维护工单”给出本页提示，不跳到养护工单。尚未建档的 BIM 构件沿用这块面板的位置，内容换成模型属性，不套用某一类设备的假台账。

场景左下有一句操作提示：点左侧列表，或点击 / 右键构件，打开资料面板。

## 5. 场景内关键原型

| 操作 | 预期反馈 |
| --- | --- |
| 打开点位聚合 | 远景重叠的普通设备变成数字气泡 |
| 关闭点位聚合 | 每个设备单独显示水滴钉 |
| 点击聚合数字 | 飞近、拆成单体，并给出完整成员列表 |
| 从列表点一个成员 | 定位该设备，模型高亮；近景隐藏图标 |
| 打开剖切并拖动 | 所选模型被切开，剖面为青色网格面，边缘发亮 |
| 剖切目标切换 | 可切全部 BIM、仅竣工段或仅施工模型 |
| 重置剖切 | 模型恢复完整 |
| 切到二维 | 剖切暂停，BIM 图标隐藏，路线仍在；重复定位不越缩越远 |
| 回到三维 | 恢复离开前的剖切 |
| 点击告警点 | 红色或橙色水滴优先被点中，不被聚合数字抢走 |
| 点击竣工设备构件 | 暖橙高亮，周围有呼吸光斑 |
| 点击摄像机构件 | 可打开模拟监控窗并定位 |
| 内部巡游 | 从路线末端进入竣工路面；可换层、暂停、检索 |
| 巡游中按 Esc | 退出并恢复外部相机、剖切、材质和业务侧栏 |
| 放大场景后再按 Esc | 退出大图 |

颜色约定：交通蓝、机电青、环控绿、监测橙、结构紫；告警红、预警橙；选中暖橙。路面默认保留原始材质，结构透视不会把路变成玻璃，只有打开“路面透视”才透明。

## 6. 原型里故意不做的事

- 不提供登录页和角色菜单。
- 不把监控窗标成 LIVE。
- 不在轮播时随机生成新告警。
- 不为无法拆分的整段灯具伪造一盏盏的独立图标。
- 业务表的多数操作按钮只表达流程位置，不代表已接通派单、审核或发布接口。
