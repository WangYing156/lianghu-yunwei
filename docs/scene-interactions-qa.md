## 重点回归修复

1. 二维定位不再依赖 2,000,000m 相机高度或累积相对缩放，改由固定米制 Rectangle 求解完整正交视锥。
2. 弹窗坐标每帧更新时不再重建内容 DOM / 图表；关闭、视频调取按钮保持可点击，图表 RAF 在回收时取消。
3. 选中/告警图标独立于普通聚合，并在拾取时优先，避免聚合数字抢走点击。
4. 打开构件或聚合成员检视时收起业务遮罩；详情/列表不再被侧栏拦截。
5. 同一世界剖切平面分别转换到施工/竣工根坐标，进入二维/巡游时暂停、返回恢复，销毁时回收。
6. 道路白色中性乘色保留原始 PBR/贴图和不透明度，结构透视不连带玻璃化道路。

## 复现

```bash
npm ci
npm run dev                 # 另一个终端
npm run typecheck
npm test
npm run build
npm run test:scene          # 本机安装 Chrome，或配置 CHROMIUM_EXECUTABLE
```

详细浏览器启动变量见 README。测试脚本 `scripts/smoke-scene.mjs` 失败时以非零码退出；机器相关报告与截图不提交。

## 数据边界

告警与普通业务点为显式模拟状态，重点监控为仓库示例图片/GIF；无后端实时告警和摄像机授权流，不宣称已接入实时服务。BIM 的几何、构件编号、位置来自真实模型。合并导出的整段灯具/构件不能逐设备定位，未伪造虚假的独立设备。
