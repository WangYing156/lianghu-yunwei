# 两湖隧道（南湖段）智能运维管理平台

Vue 3 / TypeScript / Vite / Cesium / Element Plus / ECharts 可视化前端。

## 本地运行

建议 Node.js 22 LTS，使用支持 WebGL 2 的现代桌面浏览器。

```bash
npm ci
npm run dev
```

默认地址：`http://localhost:5188`，开发服务监听 `0.0.0.0`。如需天地图底图，将 `.env.example` 复制为 `.env.local` 并配置 `VITE_TIANDITU_TK`。未开启底图时无需在线底图服务，BIM 可独立展示。

```bash
npm run typecheck          # Vue / TypeScript 类型检查
npm test                   # 路径、设备目录、图层/聚合/材质/剖切/告警测试（28 项）
npm run build              # 生产构建，输出 dist/
```

## 三维场景交互

- 底部轻量工具栏：**图层 / 场景设置 / 剖切 / 内部巡游 / 放大场景 / 复位视角**。
- 底图模式、二维/三维、材质和环境选项在“场景设置”中，默认全部折叠。
- 保留真实模型材质，施工模型以半透明方式作上下文，默认聚焦带设备的竣工段；已删除包围盒发光线框。
- 取消应用设置的相机缩放范围并关闭碰撞检测，可进入地下模型近距离查看。模型显示仍受正常视锥裁剪影响。
- “放大场景”把场景移至页面顶层；`Esc` 可退出大图。
- 二维设施点使用绝对米制窗口定位，重复点击不会累积缩放或飞向全球；所有点位使用全量目录确定位置，图层显隐不改变设施坐标。
- 施工/竣工图例、resize 把手文案和“界面+标号”/PRD 编辑功能已删除。新的无文案把手支持鼠标、触屏拖动、双击及方向键 / Home / End。

### 剖切与原始材质

- “剖切”支持 **X / Y / 水平 Z** 三轴、连续位置、反向保留，以及全部 BIM / 竣工段 / 施工模型目标选择；“重置剖切”可恢复完整模型。
- 同一世界平面转换到不同模型的根坐标系，避免施工与竣工模型原点不同导致错切；剖切范围来自真实 Tileset 包围盒。
- 二维视图和内部巡游会暂停剖切，返回外部三维时恢复；场景销毁时回收剖切资源。
- **路面默认保留 GLB 原始材质、贴图及不透明度**。施工模型透明或“竣工结构透视”不会把道路变成玻璃；只有显式开启“路面透视”才使道路透明。巡游也有独立的临时路面透视开关。

### BIM 构件图标与密集点位

- 远景为竣工目录中可独立定位的 **138 个真实设备构件**建立分类矢量图标，坐标来自构件包围球与模型变换，而不是桩号示意点。
- 图标遵循模块图层；点击可定位真实设备、高亮并打开构件属性，摄像机构件还可打开监控示例画面。
- 普通图标采用 **46 px 屏幕空间聚合**，两点及以上重叠即聚合；点击数字放大区域并提供完整成员列表，不丢弃被聚合的设备。
- 告警与选中点位在独立优先层，不参与普通聚合；聚合数字避让这些点位，拾取也优先选中/告警标记。
- 距任一设备进入 **45 m** 近景时隐藏 BIM 图标，退至 **65 m** 以外恢复，滞回避免临界距离闪烁；巡游时隐藏外部图标，只检视真实模型。
- 构件/聚合列表检视时暂时收起业务侧栏，关闭或 Esc 后恢复，避免侧栏挡住详情和操作。

### 竣工模型内部巡游

这是一套**路径巡游与构件检视**，已移除原来的 WASD 第一人称模式。

1. 在三维视图点击“内部巡游”。每次从**当前路线末端**朝内部入场，默认方向为终点→起点；较小的业务场景会自动放大。“回到巡游入口端”始终返回末端并恢复该方向。
2. 切换**下层 / 上层通道**，支持播放、暂停、正反向、进度拖动及 `0.8 / 2 / 4 / 8 m/s` 速度。
3. 拖拽画面或滚轮操作会暂停路径播放，可在当前位置环视或近看；继续播放会回到巡游路径。
4. 在搜索框按名称或构件编号查找设备。目录直接读取竣工 `scenetree.json`，当前可定位 **138 个独立构件**，包含风机、摄像头、消防泵、消防探测器、广播与疏散指引。
5. 选中设备时自动选择相近通行层并定位、高亮；开启“结构透视”可淡化遮挡结构。支持眼高与横向机位微调。
6. 点击退出或按 `Esc`，恢复外部相机、图层、材质、照明与业务侧栏。切换页面时清理巡游事件和相机更新。

**设备属性来自 BIM，而不是实时 IoT 状态。** 部分灯具等以整段合并构件导出，没有独立可用定位，故不作为独立设备伪造展示。

### 路线来源及模型更新

巡游路线不是 GeoJSON 示意线或模型包围盒中线，而是从当前竣工 GLB 中 `malu` 道路构件的**上下层真实路面**提取的 27 个采样点 / 层。运行时应用 `tileset.root.computedTransform` 转换到世界坐标，再叠加眼高；播放按弧长和真实时间计算。

```bash
npm run calibrate:roaming
```

此脚本从当前 `NoLod_7.glb` 的道路上表面重新提取路线，生成 `src/config/partialRoamingRoutes.ts`。替换模型、修改道路构件名称、层级、坐标或路线范围后，需调整脚本并重新校准，随后人工检查净空和设备检视效果；不能直接把旧路线用于任意新模型。

## 动态告警展示

- 预警横幅淡入轮播，告警面板循环展示重点事件和队列；保留原有示例事件，不随机新增告警、不伪造刷新。
- 等级统计、横幅、告警面板和模拟地图点位来自同一份事件列表。每条告警有独立稳定的 `pointId`，不再复用各模块含义不同的 `c2` / `s2` 等编号。
- 横幅、告警面板及顶部告警按钮可点击定位；若目标图层被关闭，会自动启用对应分组/子类型后定位，不会悄悄失败。
- 有告警的点位显示红/琥珀色动态图标和光圈，不被普通聚合吞掉；详情明确标记为模拟事件。
- 支持手动前后切换、暂停，鼠标悬停及键盘聚焦时暂停；切到后台暂停计时。
- 尊重 `prefers-reduced-motion`：停止自动告警轮播、呼吸动画及巡游自动播放，仍可手动检视。
- 当前事件位于 `src/config/alerts.ts`，**未接入后台实时告警接口**。

## 重点监控与视频联动

总览“重点监控”卡片、摄像机点位详情、BIM 摄像机构件属性均可打开可拖动、可放大的监控窗口，并精确定位其地图锚点；窗口提供“重新定位”，媒体不可用时显示重试状态。

**当前仓库只提供示例图片 / GIF，未接入实时监控流。** 窗口和总览缩略图明确标注“模拟画面”，不冒充 LIVE。后续可在 `MonitoringCamera.streamUrl` 接入浏览器可播放、已授权的媒体地址；鉴权与真实告警/视频服务需由实际后端提供。

## 浏览器交互回归

先在另一个终端运行 `npm run dev`，并安装本机 Chrome，然后执行：

```bash
npm run test:scene
# 或指定已有 Chromium，测试仅针对开发服务（使用 DEV 场景检查钩子）
CHROMIUM_EXECUTABLE=/path/to/chromium npm run test:scene
```

可用 `SCENE_URL` 覆盖开发服务地址。`SCENE_SMOKE_SOFTWARE=1` 仅在软件渲染验收时降低测试画布分辨率/FPS，不修改应用源码与生产配置。特殊沙箱可用 `CHROMIUM_ARGS` JSON 数组传递启动参数。

脚本覆盖 **29 项真实浏览器交互**，包括二维重复/实际点击定位、剖切跨坐标系/模式恢复、告警和视频定位、聚合成员检视、真实设备近景/高亮、巡游末端入场/材质、六模块默认图层及 resize 键盘/指针操作。失败时非零退出；报告/截图写入 Git 忽略的 `.build-check/`。本次验收记录见 [`docs/scene-interactions-qa.md`](docs/scene-interactions-qa.md)。

## 模型与部署资源

`public/三维数据/隧道施工模型/` 和 `public/三维数据/局部隧道竣工模型/` 随当前仓库提供。倾斜摄影目录 `public/三维数据/两湖倾斜/` 被 Git 忽略，需要另外部署；缺失时会跳过，不影响竣工 BIM 内部巡游。

在线底图和正射影像需要相应服务可访问；路径配置见 `src/config/tunnelTilesets.ts`、`src/config/sceneVisualPresets.ts`。子目录部署时设置 Vite `base`，模型和路线资源按该路径提供。
